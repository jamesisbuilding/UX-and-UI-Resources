# UX and UI Resources

A curated list of useful resources for UX and UI design, inspiration, and component references.

## Resources

### [21st.dev](https://21st.dev/)
A community-driven library of modern UI components built with React and Tailwind CSS. Browse, copy, and remix beautifully crafted components shared by designers and developers.

### [60fps.design](https://60fps.design/)
A gallery of high-quality interaction and animation references from real apps. Great for studying motion design, micro-interactions, and what "buttery smooth" UI actually looks like in practice.

### [Mobbin](https://mobbin.com/)
A massive searchable library of mobile and web app screenshots and user flows from real production apps. Ideal for competitive research, pattern discovery, and inspiration when designing flows.

### [Design Spells](https://designspells.com/)
A collection of small, delightful UI details — the little touches and "spells" that make interfaces feel magical. Useful for finding inspiration for polish, hover states, and tiny moments of craft.

### [Swishy](https://www.swishy.ai/)
An AI-powered tool focused on UI/UX design workflows, helping speed up ideation and design iteration.
